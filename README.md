# ราชรถ & ช่างภาพงานศพ.com — Luxury Presentation & Catalog

เว็บแคตตาล็อกและสไลด์พรีเซนเทชันระดับพรีเมียม สำหรับนำเสนองานถ่ายภาพนิ่ง วิดีโอซีนีม่า และ **Live Streaming ถ่ายทอดสด** ครบวงจร

---

## 🌟 จุดเด่นของระบบแคตตาล็อกที่สร้างขึ้น

1. **ดีไซน์ถอดแบบจากภาพต้นฉบับ 100% (Theme & Styling)**:
   - พื้นหลังสีดำด้านอมเทาเข้ม (Deep Obsidian / Charcoal Black) พร้อม Vignette ตรงกลาง
   - กรอบเส้นทองมุมเว้า (Concave Scooped Corners) ประดับด้วย **ดอกประจำยาม 8 กลีบ** สีทองอร่ามที่ 4 มุม และกึ่งกลางขอบบน-ล่าง
   - ลายน้ำโลโก้ราชรถและช่างภาพงานศพโปร่งแสงด้านหลัง
   - สีตัวอักษรสีทองอร่าม (Royal Thai Gold) และข้อความเนื้อหาสีขาวสะอาดตา
2. **เน้นความกระชับ อ่านง่ายใน 3 วินาที (Scannable Copywriting)**:
   - เลื่อนผ่านแล้วเห็นทันทีว่า **"ตอนนี้เป็นพิธีอะไร"** และ **"ทำไมต้องใช้ช่างภาพมืออาชีพแบบเรา"**
   - ข้อความเป็นแบบหัวข้อย่อย `- ` สั้น กระชับ ตรงประเด็น
3. **จัดหมวดหมู่ครบทั้ง 3 เสาหลัก + ไฮไลท์พิเศษ Live Streaming**:
   - **★ Live Streaming & จอ 65–75 นิ้ว**: ถ่ายทอดสดระดับ Full HD / 4K **พร้อมทีมงานฟรีดูแลตลอดงาน**
   - **01. การถ่ายภาพงานพิธีหลวง**: พระราชทานน้ำหลวงอาบศพ / พระราชทานเพลิงศพ / เครื่องเกียรติยศ
   - **02. การถ่ายภาพพิธีจีน**: ธรรมเนียมจีน พิธีกงเต็ก พิธีข้ามสะพาน และพิธีฝัง-เผา
   - **03. การถ่ายภาพพิธีสวดพระอภิธรรม**: บันทึกทุกบรรยากาศ ครบทุกองค์ประกอบ และแขกผู้มีเกียรติ
   - **04. ความทรงจำวันสุดท้าย**: วันฌาปนกิจ Candid & Emotion
   - **05. พิธีลอยอังคาร**: บริการติดตามดูแลส่งดวงวิญญาณสู่สุคติ
   - **06. มาตรฐานทีมช่างภาพ**: สูทสากลสำรวม อุปกรณ์ Dual-Slot ปลอดภัย 100%
   - **07. หน้าปิดการขาย (Closing Slide)**: รายการบริการครบวงจร ข้อมูลติดต่อ และ **QR Code ทั้ง 3 ช่องทาง**
4. **ระบบสแกน QR Code ครบทุกจุด**:
   - `www.ช่างภาพงานศพ.com` (ใช้ QR Code ต้นฉบับพร้อมตราสัญลักษณ์)
   - `www.ราชรถ.com` (QR Code สำหรับเข้าชมบริการหีบศพและออแกไนซ์)
   - `LINE Official: Rathcharot` (QR Code สแกนแอดไลน์ปรึกษา 24 ชม.)
5. **คลังภาพผลงานจัดเต็ม 191 ภาพ**:
   - จัดหมวดหมู่ตามโฟลเดอร์ในเครื่องจริงทุกภาพ
   - ในแต่ละสไลด์สามารถคลิกเปลี่ยนภาพตัวอย่างได้ทันที
   - มีปุ่ม **"คลังภาพ (191)"** และ **Lightbox** ซูมดูภาพขนาดใหญ่ความละเอียดสูง
6. **รองรับหลากหลายโหมดการใช้งาน**:
   - 📽️ **โหมดสไลด์พรีเซนต์ (16:9)**: กดลูกศร ◀ ▶ หรือแตะเลื่อนสไลด์บนหน้าจอ (กด `F` เปิดเต็มจอ)
   - 📜 **โหมดเลื่อนอ่าน (Continuous Catalog)**: สำหรับส่งให้ลูกค้าเลื่อนดูบนสมาร์ทโฟนหรือแท็บเล็ต
   - 🖨️ **บันทึกเป็น PDF**: มีสไตล์พิมพ์หน้ากระดาษแนวนอนสวยงาม พร้อมพิมพ์หรือส่งไฟล์ PDF ให้ลูกค้าทาง LINE ได้ทันที
